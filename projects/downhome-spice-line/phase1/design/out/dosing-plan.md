## Growth to the full range

With every product running, the same rules use **12** bins (salt, garlic, paprika, onion, black-pepper-coarse, red-pepper, black-pepper, spinach-powder, lemon-peel, cayenne, cinnamon, tomato-powder); it fits the bank. Auto-dosed share 62.4 %.

Would still be hand-weighed for lack of positions: red-bell-pepper, turmeric.

## Lot traceability for bins

A bin mixes lots when it is topped up. The MES records every lot poured into a bin, and a batch dosed from that bin is traced to every lot present since the bin was last run empty. Run each bin empty at least once a week, at the low-level switch, to keep that set small.

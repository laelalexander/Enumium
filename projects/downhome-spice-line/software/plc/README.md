# PLC programs (IEC 61131-3 Structured Text)

| File | PLC | What it does |
|---|---|---|
| `io_map.st` | 601, 602 | Physical I/O, generated by `gen_tags.py` from `design/io.json` (117 points). |
| `tags.csv` | 601, 602 | Same I/O as Studio 5000 alias tags with wire and cable numbers in the description. |
| `BlendTrain.st` | 601 (CompactLogix 5069-L320ER, blending) | ISA-88 batch phase: pre-check, salt charge by weight, majors and premix dump with scan, timed mix, QC sample hold, metered discharge through sifter, magnet and metal detector to the bulk bag, drain, hold/abort. |
| `DosingStation.st` | P1-225 (WAGO PFC200 750-8212, CODESYS 3.5, Phase 1) | Bin ring dosing: one feeder at a time into weigh hopper P1-220, fast/slow cut-off with learned in-flight per bin, jog top-up, no-flow / timeout / over-dose holds, bin-low probe check, then valve P1-223 and flexible screw P1-224 to blender P1-301 with permissives. Exchanges the dose list and each result with the MES (`/api/batch/<id>/doselist`, `/api/dose`). I/O is declared in the file. |
| `PackLineA.st` | 602 (CompactLogix 5069-L320ER, line) | PackML state machine for line A, machine permits, starve/block, vision reject shift register with confirm, case count, first-out stop reason. |

Target is Studio 5000 v34+ (Structured Text routines); the code is plain IEC 61131-3 and also compiles in CODESYS with `io_map.st`.
These are commissioning-ready drafts: timers marked "tuned at SAT" and every OEM handshake must be checked against the OEM's I/O manual at FAT.
The safety functions (e-stops, guard doors, blender cover) are hard-wired through safety relays SR-601/SR-602, not this code.

Regenerate the tag list after any I/O change: `python3 gen_tags.py`.

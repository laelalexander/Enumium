Shop agent

The shop agent is a small program on a shop PC. It picks up the jobs you send from Production, hands them to the machines on the shop network, and reports their status back here. Pyslate can't reach your machines directly, so the agent calls out to it.

{% if not token %}

The agent API is off. Add a token to the server's settings and restart Pyslate. Re-running install.sh on the Droplet does this for you.

{% else %}

1. Download the agent

Download pyslate-shop-agent.zip It includes agent.json with this shop's machines and token already filled in.

2. Fill in the machines

  • xTool lasers work straight away: each job opens in xTool Studio on the shop PC with the settings in its note. Add each laser's IP address as host to see whether it's on the network.
  • Bambu Lab: turn on LAN mode on the printer, then fill in host, serial and access_code, and the Bambu Studio command line with your exported presets. Run pip install paho-mqtt.
  • JG Maker A8S: set the slicer command (PrusaSlicer or Orca with your A8S profile) and run pip install pyserial. Only one program can use COM4, so close Nero 8 while the agent prints.
  • Tormach and others: the folder driver drops each file into a folder, such as a share PathPilot can see.

Turn a machine on with "enabled": true.

3. Start it

Unzip it on the shop PC (Python 3.11 or newer), then double-click run-agent.bat, or run py -3 -m shop_agent --config agent.json. Check the machines first with --status.

Shop-floor screens

The same download has a full-screen terminal board for the workshop: machine status, progress bars, queues, a schedule strip and orders by due date. Run py -3 -m pip install rich once, then run-hud.bat, or run-hud.bat --line laser --title "LASER BAY" for one area per screen.

Agent token

The agent sends this with every call. Keep it private; change PYSLATE_AGENT_TOKEN in /etc/pyslate.env to revoke it.

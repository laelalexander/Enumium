# Deploy: hub web console fix for large run logs (2026-11-25)

**What it fixes.** `/anatomy-hub/console/api/projects/<id>/events` read a project's whole `.anatomy/events.jsonl` into memory.
- On the 105 MB log (3D printer) the hub process peaked at 506 MB RSS.
- The service has `MemoryMax=512M`, so systemd killed it: nginx returned 502 and the Live view stayed empty.
- Affected projects: the 3D printer, the Wren drone, NB-1 and NBED rev B.

**The change** is in `console.js` only. `hub.js` is unchanged.
- The replay streams the log from disk line by line.
- It sends the run's first 256 KB and its last 4 MB, with a short note in between.
- Lines over 64 KB are shrunk by cutting long strings, and it waits for the socket to drain.

**Local test on the 105 MB log:**

| | Peak RSS | Sent | Events |
|---|---|---|---|
| Deployed code | 506 MB | 110 MB | — |
| Patched code | 54 MB | 400 KB | 279 |
| Patched, 5 parallel requests | 69 MB | — | — |

The console UI from the same commit renders the stream correctly: the prompt, the note, the latest work, and Results with the run summary.

## Steps

Run these from a PC that has the server key (e.g. Ambient-Networks: `C:\Users\Owner\.ssh\nero_cloud`).
Copy `console.js` from this folder to that PC first.

1. Copy the new file to the server, staged in /tmp. This changes nothing yet.

   ```powershell
   scp -i $HOME\.ssh\nero_cloud .\console.js root@206.189.202.27:/tmp/console.js.new
   ```

2. Open a shell on the server:

   ```powershell
   ssh -i $HOME\.ssh\nero_cloud root@206.189.202.27
   ```

3. Check what is running, and back it up:

   ```bash
   sha256sum /opt/anatomy-hub/console.js /tmp/console.js.new
   # The first should be b6ed49c6... (the fb06f8a deploy). If it differs, the server has newer code: stop and diff it first.
   tar czf /root/backup-anatomy-hub-20261125.tgz /opt/anatomy-hub/hub.js /opt/anatomy-hub/console.js /etc/systemd/system/anatomy-hub.service
   systemctl show anatomy-hub -p NRestarts        # note the number
   ```

4. Install the new file and restart only the hub:

   ```bash
   node --check /tmp/console.js.new && install -m 644 /tmp/console.js.new /opt/anatomy-hub/console.js
   systemctl restart anatomy-hub && sleep 2 && systemctl is-active anatomy-hub
   curl -s http://127.0.0.1:4380/api/health; echo
   journalctl -u anatomy-hub -n 20 --no-pager
   ```

   Do not run deploy.sh. It reloads nginx and recopies the console UI.

5. In a browser, open https://pyrails.com/anatomy-hub/console and open the 3D printer, the Wren drone, NB-1 and NBED rev B. Each should show its Live view with the "history is not shown" note, and the Results and Simulate tabs.

   Then check that NRestarts has not grown:

   ```bash
   systemctl show anatomy-hub -p NRestarts
   ```

## Roll back

```bash
tar xzf /root/backup-anatomy-hub-20261125.tgz -C / && systemctl restart anatomy-hub
```
